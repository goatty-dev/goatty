# Coding agent logos

Tab icons for coding agents (`src/agent/mod.rs`). From
[LobeHub Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg` 1.103.0, MIT License, Copyright (c) 2023
LobeHub), with their `<title>` and inline styles removed and a 64 px canvas
so GPUI rasterizes them sharply.

| File | Source | Drawn |
|---|---|---|
| `claude-code.svg` | `claudecode-color.svg`, redrawn on its exact 16×16 pixel grid (the source's rows sit a third of a cell off it) | in its colors, at whole pixels per cell |
| `codex.svg` | `codex-color.svg` | in its colors |
| `gemini-cli.svg` | `geminicli-color.svg` | in its colors |
| `copilot.svg` | `copilot-color.svg` | in its colors |
| `antigravity.svg` | `antigravity-color.svg` | in its colors |
| `amp.svg` | `amp-color.svg` | in its colors |
| `qwen.svg` | `qwen-color.svg` | in its colors |
| `opencode.svg` | `opencode.svg` (on a 12-cell grid) | tinted, at whole pixels per cell |
| `cursor.svg` | `cursor.svg` | tinted with the tab's text color |
| `goose.svg` | `goose.svg` | tinted with the tab's text color |
| `pi.svg` | `pi.svg`, redrawn on its exact 4×4 grid | tinted, at whole pixels per cell |

The logos are trademarks of their owners and are used only to show which
program runs in a tab.
